# 用产品资料配置语音讲解和问答助手

完成这条流程后，你会得到一个绑定产品资料的角色，并能在真实服务配置下用语音向它提问、核对答案。先使用纯语音；数字人可以最后添加。

## 开始前

- 使用可管理个人角色与资料的账号，或先按[本地启动指南](LOCAL-DEVELOPMENT.md)运行应用。公开站权限与额度由运营方配置。
- 为真实问答配置兼容的回答模型、知识检索工具路径，以及语音识别与合成服务。[云服务配置](CLOUD-SERVICES.md)
- 确认浏览器可访问麦克风；通常需要 localhost 或 HTTPS。未配置凭据的演示回复不代表真实资料问答。

## 1. 准备一份简短的产品资料

先用下面的虚构示例，避免首次配置时混入复杂规则。也可以直接使用自己的产品 FAQ；每份资料应聚焦一个主题，并写明产品名、条件和版本。

```text
资料名称：星河产品说明 v1

星河是一款面向小团队的项目协作工具。
星河主要功能：任务看板、项目文档、团队成员协作。
星河试用期限：14 天。
星河试用人数：每个团队最多 5 人。
星河导出方式：在项目设置中选择“导出 Markdown”。
星河客服服务时间：工作日 09:00—18:00。
这份资料没有列出付费价格、退款政策或手机端支持情况。
```

进入「资源库 → 知识库」，新增资料并粘贴正文，点击「创建资料」。已有文件可以导入文字型 PDF、DOCX、Markdown 或 TXT；扫描 PDF 目前不支持 OCR。提取后正文每份最多 32,000 UTF-8 字节，超限请按主题拆分。[完整导入说明](../KNOWLEDGE-BASE-GUIDE.md)

## 2. 先测试检索

在资料列表勾选刚导入的资料，展开「测试检索」，分别检索「星河试用期限」和「星河导出方式」。展开引用片段，核对是否包含 14 天与导出 Markdown 的原文。

测试检索返回资料片段，不生成助手回答。未命中时检查正文和勾选范围，再用原文中的关键词提问。默认检索是关键词片段检索，不保证同义改写和复杂条件都能命中。

## 3. 配置角色并绑定资料

进入「角色」，创建个人角色或打开可编辑的角色，名称可设为「星河产品助手」。在角色设置中：

1. 选择已配置语音服务支持的声音。
2. 在「知识库」选择「星河产品说明 v1」，确认保存完成。
3. 检查工具选择与权限，确保当前模型和会话路径能够使用知识检索。仅导入或勾选资料不能证明检索已在实际对话中执行。
4. 在人设说明中加入下面的回答要求。

```text
你是星河产品助手，负责简洁讲解产品并回答问题。
回答星河的功能、试用和使用规则时，先检索绑定的知识库。
保留原文中的条件和限制；每次先回答当前问题，用户需要时再展开。
资料没有提供的内容，明确说“当前资料没有说明”，不要编造。
用户纠正问题时，按最新问题重新核对资料。
```

人设是对模型的指导，需要验证实际行为。角色配置、全局服务默认值与个人供应商设置各有作用域。[角色配置说明](../guides/ROLE-CONFIGURATION.md)

## 4. 开始语音对话并核对结果

使用该角色选择语音模式，开始会话并允许麦克风。依次尝试：

| 你可以问 | 应核对的内容 |
| --- | --- |
| 请查一下资料，简要介绍星河 | 面向小团队，包含任务看板、项目文档与成员协作 |
| 星河试用期限是多久？ | 14 天 |
| 星河试用人数是多少？ | 每个团队最多 5 人 |
| 星河如何导出？ | 在项目设置中选择导出 Markdown |
| 星河付费价格是多少？ | 资料未说明，不能给出编造的价格 |
| 讲解过程中说“停一下”，再问导出方式 | 检查是否停止旧回答，并回答新的问题 |

继续用自己的常见问法测试停顿、短回答和纠正。表中的答案是核对目标，不是已经完成的真实供应商验收结果。测试检索成功、文字问答正确和真实语音体验通过是不同的验证步骤。

发现错误时先检查引用片段、角色绑定与工具调用，再检查回答模型和服务状态。记录使用的语言、模型与版本，便于重复验证。[知识库排错](../KNOWLEDGE-BASE-GUIDE.md#常见问题)

## 5. 换成自己的产品资料

使用示例跑通流程后，导入当前有效的产品说明和 FAQ。逐项核对功能、条件、例外和资料未覆盖的问题。更新原文后重新测试检索，再开启新会话核对答案，避免旧会话中的资料影响验证。

产品资料与记忆分开管理：知识库提供参考原文，长期记忆保存用户与角色范围内的长期信息；对话历史用于查看与续聊。[记忆与历史](../MEMORY-AND-HISTORY-GUIDE.md)

## 可选：为助手添加数字人

语音问答验证完成后，再选择云实时数字人、本地口型合成或预生成动作编排。云服务需要单独配置与授权；本地合成另有算力要求；动作视频不逐字匹配口型。核对人物显示、声音和打断行为后再用于展示。[数字人路线](../DIGITAL-HUMAN-DRIVING.md)

准备给其他人使用时，再按[自行部署指南](../deployment/public-trial.md)配置认证、持久化、凭据与额度。
