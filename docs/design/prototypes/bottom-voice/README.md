# 底部声音状态设计原型

日期：2026-09-11。用户要求保存当前光束，并提供其他同样依托窗口底边的方案。

## 文件

- `bottom-beam-v1.fragment.html`：截至本次归档的原始内嵌代码，原样保存，包含 CSS、Canvas 绘制和本地交互。后续探索不覆盖这份版本。
- `bottom-beam-v1.html`：上述代码导出的完整 HTML，可直接用浏览器打开。
- `bottom-voice-options.fragment.html`：四种声音状态的对比预览源代码。
- `bottom-voice-options.html`：四方案对比的完整 HTML，可直接打开。

均未接入真实麦克风、音频播放或服务端。音量滑杆模拟归一化电平；D 的柱高是程序化节奏示意，不是真实 FFT 频谱。文本是预览文案，尚未获用户定稿确认。点击选择仅记录当前预览偏好，不更改正式产品。

## 四种方向

| 方案 | 表达 | 取舍 |
| --- | --- | --- |
| A 丝带光束 | 黄、青、粉、紫色丝带相互交叠，贴底向上展开 | 识别度强、能量感足；彩色面积较多 |
| B 柔和极光 | 多个柔和光峰从窗口底边向上扩散 | 氛围柔和，适合陪伴；音量变化轮廓较含蓄 |
| C 极简弦线 | 纤细的青紫色弦线轻轻起伏 | 长时间阅读更克制；视觉冲击较弱 |
| D 节奏脉冲 | 短光柱沿底边随能量升降 | 状态反馈清楚；更偏工具感 |

所有方向以窗口底边为锚点，无圆壳；无声回落到细线，思考仅底边亮点缓慢移动，静音为静态低亮线，连接中断为琥珀虚线并配状态文案。AI说话和用户说话使用相同音量驱动规则，声音来源靠文字区分，不只靠颜色。

预览使用共同音量参数和时间源，保留每种方案自身的几何尺度。振幅平滑上升约75ms、回落约230ms；这仅为前端原型参数，不是端到端语音延迟承诺。隐藏或移出可视区时暂停动画，减少动态偏好下展示静态能量形态。

## 正式接入时

把滑杆替换为实际麦克风/播放归一化电平；区分麦克风静音和AI播放。声场层不捕获点击，独立于控制区且不改变布局高度；底部输入、系统安全区与键盘展开需在真实页面中再验证。错误恢复、结束回顾仍沿用设计方案。

原始灵感：[Liquid Orb Editor](https://lersent001.github.io/orb/) 的 Siri 光束。保存的是本会话的概念重绘，不是其原始着色器的逐像素复制。完整导出由 visualize 技能的 render.py 生成；片段中的可选 Tweak 控件在独立浏览器无宿主时自动忽略。使用者仍可通过可见控件切换状态和音量。

## 选定方案

用户已明确选择 **B · 柔和极光**。后续正式页面的底边声音视觉以 B 为准。

- `bottom-aurora-selected.fragment.html`：默认单独展示并选中 B 的设计源代码。
- `bottom-aurora-selected.html`：可直接打开的选定版本。

保留 A 的原始归档与四款对比，不覆盖。此次确认的是视觉方向；引导语和“关闭麦克风但AI仍在讲话”的声音来源规则仍待用户核对，正式产品页面尚未替换。

## 正式页面接入

用户随后要求将四种效果全部加入配置，默认 B；该项已实现。

入口：首页会话配置工作台 → 通用 → 底部声音效果；通话内会话设置 → 通用 → 底部声音效果。四个选项即时生效，使用 `openrealtime-bottom-voice-style` 保存选择；无记录或记录无效时默认 `aurora`。

实现：`src/lib/bottom-voice-style.ts` 定义选项及音量规则；`src/hooks/use-bottom-voice-style.ts` 同步保存和同页变化；`src/components/call/bottom-voice-style-picker.tsx` 提供配置；`bottom-voice-edge.tsx` 管理底边层生命周期；`bottom-voice-renderer.ts` 绘制四种效果。视觉层使用现有引擎的 microphone/playback level，所有页面形态共享一个窗口底边锚点。

验证：20项相关单元/组件回归测试；模拟语音浏览器验证默认、四选项、刷新保存、通话内切换、三种布局、390×844贴底、结束清理。浏览器无脚本错误。真实设备语音延迟和托管数字人播放电平不在本轮验收范围。
