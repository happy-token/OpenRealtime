# 主页舞台视觉原则

主页以一个完整的大背景承载数字人或声音视觉，配置入口作为悬浮控件叠加其上，不把配置内容包进独立面板或卡片窗口。

- 形象、动作和口型对齐列表直接出现在舞台边缘，列表本身无背景、边框和阴影。
- 口型对齐不设置独立的右侧列表或隐藏触发条。有口型对齐的动作底片显示为叠层状态；点击底片后，全部口型对齐从卡片上方向外展开，素材名称固定显示在各自卡片顶部。
- 只有需要明确操作状态的按钮、选中项和小型标签使用毛玻璃表面，避免形成大块浮窗。
- 毛玻璃表面的透明度和模糊度统一读取主页工作台视觉变量，并由侧边栏“设置 → 外观”中的工作台透明度、毛玻璃模糊控制。
- 导航与悬浮按钮保持圆角、半透明和轻量高光；内容列表优先呈现素材本身。
- 移动端可以保留用于切换形象、动作、口型对齐的底部控制条，但内容区域仍保持透明，不增加背景窗口。
