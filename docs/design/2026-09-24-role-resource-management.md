# 角色配置与资源管理边界

## CAPABILITY

登录用户在角色页选择和组合声音、人设、数字人、动作、工具与知识资料；在资源中心创建和管理这些可复用资源，包括修改自定义资源名称。角色页保持面向一次角色配置，资源中心承担跨角色的资产生命周期管理。

## CONSTRAINTS

- 角色记录只保存资源标识和当前选择，不复制资源名称或媒体内容。
- 改名不改变资源标识，因此所有已绑定角色应自动显示新名称，不需要逐角色迁移。
- 内置资源只读；只有当前操作者有权管理的自定义资源展示改名或删除操作。
- 删除必须明确提示对已有角色引用的影响；改名不能触发重新生成音色、动作或口型对齐。
- 数字人动作和口型对齐归属于数字人形象，管理入口应进入对应形象上下文，而不是建立一份脱离形象的重复目录。
- 资源库是与角色并列的工作内容，不归入“设置”或账户菜单；进入资源库后复用设置页的二级侧边栏结构承载资源分类。

## IMPLEMENTATION CONTRACT

- 角色页：选择供应商、音色、人设、形象、动作、口型对齐、工具和知识资料；允许创建缺失资源；提供直达管理入口。
- 资源中心：通过主导航中的“资源”进入 `/resources`；声音、人设、数字人、动作与口型对齐、工具和知识库作为二级侧边栏选项，不再重复显示页内横向标签。
- 声音资源：供应商选择、音色克隆、官方音色和方言支持分别作为纵向可展开模块；展开供应商模块后显示供应商列表，展开其余模块后显示单列可滚动目录并支持选择和试听。“新建克隆音色”只位于音色克隆模块右侧，资源库与角色设置共用同一套录音/上传克隆能力，当前仅阿里云百炼开放克隆。
- 数字人资源：数字人是一级资产，动作归属于数字人，口型对齐继续归属于动作。侧边栏只保留“数字人”，动作生成与口型对齐工作台作为数字人页内的制作入口；旧的 `tab=motion` 链接兼容跳转到数字人资源。
- 克隆音色：列表项支持改名和删除；改名只更新展示名称，供应商音色 ID 保持不变。
- 数字人动作：从角色当前动作直达数字人详情；详情页支持修改数字人、动作和口型对齐名称。
- 状态变化：创建后可回到发起角色并选择新资源；改名后重新读取目录即可显示新名称；删除后失效引用必须在角色配置中可识别。

## NON-GOALS

- 不把官方音色、内置数字人或内置工具开放为可改名资源。
- 不在角色记录中维护资源名称快照。
- 不新增一套独立的“动作资源库”数据模型；动作继续归属数字人。
- 本次不改变供应商侧音色 ID，也不因改名重新克隆音色或重新生成视频。

## OPEN QUESTIONS

- 生产环境中的克隆音色当前属于供应商工作区级资源；若未来开放多租户自助管理，需要把展示名称、所有权和引用检查迁入用户数据库。
- 删除仍被角色引用的资源时，是阻止删除、自动回退还是允许失效，需在正式多用户发布前统一策略。

## HANDOFF

当前能力可直接实现。角色页维持配置职责，资源中心作为主导航中的一级管理入口；后续多租户发布前再评审所有权与删除引用策略。
