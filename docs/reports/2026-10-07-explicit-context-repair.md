# 显式请求与模型交付的公开后上下文纠正

日期：2026-10-07。前置提交：`b886827`。本批补齐阶段3中的显式请求、手动文字与 MODEL_RESPONSE 交付的当前会话纠正编排，采用 [ADR0143](../adr/0143-explicit-reply-context-repair.md)。完整阶段3/G3保持开放。

## 行为

迟到播放事实改变已听上下文后，显式回复现在能按现有 actor 许可生成新的回复版本。原输入、输入版本和交付父项保留；工具结果参与上下文，不能成为新用户授权。新版本共享原绝对截止、最多两次纠正、资源关闭和播放事实等待，不重复执行工具或委派。

Core 独立取得同 lease 的完成用户输入锚；MODEL_RESPONSE 的工具来源继续是父项。手动文字以 durable item_id 建立版本身份。新的手动输入覆盖未提交语音时记录旧原文与替换 item_id；同一 ASR 输入开始回复时保留后续语音补充。

TurnController 的当前请求、赋值版本和模型交付准入身份避免旧事件覆盖新请求。合法排队后继保持可用；新输入优先。失败/取消准入仅在当前赋值仍匹配时回滚；期间已开始的原合法交付使用保存的 Started 事实恢复当前所有者，不等待已经消费的事件。内部自动/纠正请求与公开调用共享准入记录。会话内幂等命令表保存原准入结果，重放不能获得新权限，并发重放的等待者取消不能取消原请求。它不是跨会话持久动作账本。

原有模块内完成修改，没有新增生产模块、业务 actor 或播放队列。ResponseStarted 的可选 source_item_id 用于关联实际模型触发来源；现有前端帧无需变化。

## 回归与发现

新增 `tests/realtime/test_explicit_context_repair.py` 共27项，使用生产 actor/Core/Managed/Journal/TurnController/Bridge，只有 ASR事件、模型/TTS和renderer回执受控。

- 显式 RequestResponse、手动 USER、USER 模型交付、TOOL_RESULT 模型交付，以及手动 USER 后交付工具结果：新版本身份、原输入和父项保留，不重复用户行。
- 新 durable USER 在请求之前阻止旧纠正；新文字保留旧待提交语音证据，已有 ASR 回复保留后续语音。
- 旧 ItemDeliveryStarted 迟到不得恢复所有者；旧 ResponseStarted 不得清除新请求；准入等待取消恢复原合法所有者。
- 合法双交付队列、失败请求后的原排队交付；旧交付和显式请求的幂等重放；不同内容同键拒绝；并发重复等待者取消不影响原请求；原自动/纠正内部命令重放也不恢复旧权限；新请求等待失败期间合法交付已开始可继续纠正；非法新键复用交付/回复ID，不得删除原队列准入或改写原日志输出item_id；跨模式 DISPLAY_ONLY 失败也不删除 MODEL 原准入。
- 两种显式来源 × 工具/委派请求：即使换新动作身份，纠正仍拒绝外发执行，执行次数为零。

初始四种来源测试先失败；两位审查者用真实组合链复现手动工具输入身份、取消回滚及迟到事件问题。合法双队列、旧幂等交付/内部请求重放、回滚期间已开始交付及非法ID别名均各自落盘红回归后修复。扩大测试还暴露准备时 yield 的夹具签名未更新和 COMMITTED 种子被错误视为新手动完成输入；已更新夹具并只以完成 USER 建立新身份，原 endpoint 输入预算故障关闭行为保留。末次扩大测试发现既有 queued-output 契约要求错误消息保留 cannot be reused，已兼容该文本，拒绝行为不变。
