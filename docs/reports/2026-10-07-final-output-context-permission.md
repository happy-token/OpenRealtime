# 最终队列交付的已听上下文许可

日期：2026-10-07。前置提交 `ecfcf10`，对应 ADR0137与实施计划阶段3。本批完成 Core 生成依据在排队/最终帧交付期间的许可校验；不关闭公开后新版本衔接、真实renderer或G3。

## 问题和修复

旧许可只在生成时校验。实际Managed队列中的音频，即使生成已经结束、先前回复的迟到播放回执改变了模型可见历史，仍可被Bridge发送。新回归先复现两个失败，分别覆盖生成在途与已完成。

Core保留**一份**最后公开Brain回复的输入/历史投影依据，跨越生成完成。所有模型投影写入点在任何actor等待之前同步核对，变化后永久置该依据失效；只有样本位置变、模型可见已听文本未变则保留许可。回复身份公开后不能重用，下一公开依据替换时旧输出保持fence。没有新增业务actor或第二输出队列。

装饰队列的已有 output_delivery_allowed 读取同一失效标记。新增纯读取 output_context_current 接缝由六层既有装饰/proxy转发，允许在终态事实派生字幕/音频时检查许可。读取不创建任务、不提交输入或决定语义；投影写入由Core登记一个有所有权的异步撤权/停播操作。

有效回复正在等待模型或TTS时，前沿变化发出事件并唤醒这些等待。模型已完成但公开终态仍留在队列时，保留原Completed事实，另记带原response_id的response_context诊断及停止操作，不再发第二终态。普通附加输入已经按actor规则撤权时，不触发通用失败撤权，独立的当前句许可继续按既有规则验证。

## 最终帧与供应商输入等待

Bridge在最终send前对文本、语音文本、字幕、PCM和Completed派生的字幕/终包重复纯读取。停止屏障/帧准备期间变化也不得发送旧内容。PCM的样本数量、音频时钟与序号在最终准入回调中同步发布，拒绝包不占样本位置；真正发起send前发布，仍支持立即到来的客户端回执。

原始Completed等事实继续穿过装饰链供Journal/诊断结算；Bridge可以拒绝基于过期依据生成的字幕和终包。外部SpeechAudioCompleted按自身speech_id校验，而非继承的来源response_id；源上下文保持原样，撤销来源不等于撤销独立外部播报。

TTS默认16项文本输入队列也可能阻塞Append或Commit。公开响应的Start/Append/Commit与同一个前沿事件竞争，失效时取消并加入实际发送任务的清理。启动前两次读取失效状态；启动操作发起前登记泵/清理归属，因此即使供应商已开始、确认返回前才发生失效，既有关闭操作也能找到它。不会仅以失败终态假定provider已经退出。

## 验证

新增34个本地受控回归：

- 三种真实装饰配置×生成在途/完成×已听文本变化/仅样本变化，12项。
- PCM、文本、字幕、Completed派生帧在最终发送前等待×变化/不变，8项；拒绝PCM不增加时钟。
- 已完成回复的原始单一终态与精准诊断、纯读取不改状态、已发布ID不能重新绑定，2项。
- 默认16项TTS文本队列满载：16段后的Commit、40段中的Append×变化/不变，4项。
- ModelSpeech记录等待前沿变化与Native已启动/确认返回前变化，2项，检查真实finally和资源归属。
- 外部终包：无来源/普通来源/已撤来源×外部许可有效/已撤，6项，检查实际末包。

旧完成回归明确等待首次语义发布后才注入播放变化，避免将供应商yield误当公开完成。原TTS背压用例继续断言原上下文失败、真实清理、无旧输出与无残留；由于现在更早被前沿事件唤醒，错误位置可从TTS交付提前到等待模型/模型完成，未弱化核心语义断言。

所有模型/供应商均为本地替身，Managed/Core/Native/Journal/Bridge与版本actor是生产实现。不调用真实供应商，不重启用户服务，不迁移数据库，不宣称物理音频验收。

最终全量Python：2151 passed、69 skipped、3 subtests passed，46.60秒。6个生产模块Mypy、14个Python文件Ruff及diff检查通过；两位独立审查分别复跑104项、219项定向回归并批准。另修正旧双工TTS测试对诊断事件插入位置的固定假设，仍严格检查四类输出顺序、首包早于模型结束及finally清理；修正后72项定向回归通过，全量无新增警告。

## 限制与剩余任务

自动生成新的公开回复版本、supersedes、已听依据及已经执行的工具/委派副作用衔接仍待实施。未执行的旧请求在队列出口拒绝，已执行副作用不能借重生成重放。真实浏览器生产链路与数字人G3、误打断恢复G4、G0–G5其他验收及横向诊断/双路录音/Agent接口仍开放。

一份公开依据不会随回复累积，但现有历史身份/幂等集合的整个会话预算仍按资源轨道开放。永久不协作provider的整个shutdown硬截止也仍开放。最终复验到达transport.send准入边界；已经交给网络的内容需要精确停止协议与客户端许可控制，不把该服务器回归当成物理扬声器无重叠证明。

9个生产文件扩大Mypy检查发现runtime、tool_controller、endpoint_bridge共12项既有诊断。已从ecfcf10取出三份源码单独复查，得到完全相同12项；本批没有新增类型诊断。其余6个生产文件单独检查通过。不能宣称整个9文件Mypy全绿，既有类型修复继续保留。
