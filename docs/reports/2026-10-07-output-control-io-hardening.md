# 2026-10-07：非合作停播控制 IO 加固

前批提交`43bb066`和`5eac78b`接入恢复执行及未知停播异常子集。本批继续实施计划中“每次等待有截止、非合作取消保留真实归属”的要求，采用[ADR0147](../adr/0147-owned-output-control-io-deadlines.md)。完整G4与其他轨道仍开放。

## 发现及实现

真实Bridge/正式Endpoint的恢复通知被适配器无限吞取消时，原50ms截止过去、200ms调用者仍未返回。两个确定性回归先红。恢复通知现使用独立登记的IO任务与asyncio.wait，超时返回并封锁输出，不能通过吞取消延长调用者等待。

相同方法覆盖精确和兼容停播发送、失败通知与连接关闭。独立审查发现兼容/目标缺失分支仍有旧wait_for，本批一并迁移，不能仅保证精确分支。正常关闭后的发送超时曾误发故障，四个不手动取消调用者的回归复现；关闭标记保护修复后，保留session_closed，避免把正常结束计作故障。

每个Bridge有8个未退出控制IO的预算。取消或超时不释放预算；close有限等待后保持残留归属，实际退出回调清理。迟到异常由回调读取并记录，任务名带Voice Session ID。复用既有Bridge，不增加第二个业务控制器或输出队列。原事实存储/投影的任务归属不改成此控制IO集合。
