# Jev turn-taking 提示词实验

日期：2026-09-20。仅修改评测脚本中的可选 Jev 提示词，默认基线、DeepSeek 提示词
及生产停播规则均不变。TypeSafe `Choice` 的选项仍是原六类打断和三类完整度。
候选版在 `scripts/evaluate_turn_taking_models.py` 的 `SOURCE_AWARE_INSTRUCTIONS`：
先利用文字化声源观察排除电视、旁人、回声及非语音，再判断用户意图；完整度增加
句尾必需宾语/谓语与缺少可追问执行参数的区别。遵循 TypeSafe 的 state 与 Choice
文档（https://docs.typesafe.ai/concepts/state、https://docs.typesafe.ai/primitives/choice）。

原 52 条挑战集已被用来诊断基线，故仅作为开发集：候选提示词单轮完整度 21/24
（原五轮基线 105/120），六类打断 23/24（原五轮基线 80/120）。候选仍将
`hc04/hc14/hc22` 判为完整、将 `hi18` 的旁人对手机讲话判为新任务。
原 30 条易样例单轮复核，两个任务的确定性标签均未回退（8/8、18/18）。

## 统计口径

在确定候选提示词后，用额外的 20 条合成文本保留集分别运行旧版和新版，每条各
重复 5 次，共 200 次 Jev 请求（每版 100 次）。完整度 8 条（完整/不完整各 4），
打断 12 条（需停播 6、不需停播 6）。下表分母是五轮预测数，而非独立样本数；
五次重复不能当作五倍样本量。两版请求/解析失败均为 0/100。

- 完整度以**不完整**为正类：TP=正确等候，FP=完整却判不完整，FN=不完整却判完整，
  TN=完整且判完整。本保留集没有待复核真值，也没有输出 `uncertain`。
- 打断以**需要停播**为正类：`stop`、`correction`、`interrupt` 视为停播；
  `backchannel`、`ignore` 和 `uncertain` 在**本报告的动作映射中**视为不执行停播。
  真值为 `ignore` 或 `backchannel` 时不应停播。TP/FP/FN/TN 均按此定义。
- 精确率=TP/(TP+FP)，召回率=TP/(TP+FN)，误停播率=FP/(FP+TN)，
  准确率=(TP+TN)/总数。F1 为精确率与召回率的调和平均。

| 指标（40 次预测，正类=不完整） | 旧版 | 声源优先版 |
| --- | ---: | ---: |
| 准确率 | 26/40 (65.0%) | 28/40 (70.0%) |
| 精确率 | 6/6 (100%) | 8/8 (100%) |
| 召回率 | 6/20 (30.0%) | 8/20 (40.0%) |
| F1 | 46.2% | 57.1% |
| TP / FP / FN / TN | 6 / 0 / 14 / 20 | 8 / 0 / 12 / 20 |

重点是漏判不完整仍然严重：新版 20 次不完整表达中有 12 次被当成完整，不能只看
准确率提升 5 个百分点。`phc02`、`phc04` 在两版中仍各五次误判为完整；
`phc08` 由 4/5 错改善为 2/5 错。

| 指标（60 次预测，正类=需停播） | 旧版 | 声源优先版 |

下表是**原始标签**而非停播动作。模型仍从 `backchannel`、`stop`、
`correction`、`interrupt`、`ignore`、`uncertain` 六项中选一；保留集的确定
真值只覆盖前五项，不能验证 `uncertain` 真值识别。

| 原始多分类指标 | 旧版 | 声源优先版 |
| --- | ---: | ---: |
| 标签准确率 | 45/60 (75.0%) | 60/60 (100%) |
| `ignore` 精确率 | 5/5 (100%) | 20/20 (100%) |
| `ignore` 召回率 | 5/20 (25.0%) | 20/20 (100%) |

二分类口径仅是对同一六类输出的后处理，**不是重新调用二分类提示词**。旧版
`phi02`（电视“先暂停播报”）和 `phi12`（噪声误转“停”）各五次都误判为 `stop`；
`phi11`（回声）五次选 `uncertain`，在六类准确率中计错，但二分类按不执行停播
计算。新版这三例都选 `ignore`，六条真实用户打断均五次正确。

## 响应时间

请求均串行运行，耗时为客户端发起请求到完整响应解析的 wall time；P90 对每组
耗时采用 nearest-rank，**不是**首 token 时间，也不包含 VAD、ASR 和真实停播。

| 请求组（每版次数） | 旧版平均 / P90 | 声源优先版平均 / P90 |
| --- | ---: | ---: |
| 完整度（40） | 396.1 / 737.5 ms | 399.4 / 710.4 ms |
| 打断（60） | 326.0 / 391.1 ms | 324.1 / 401.9 ms |
| 全部（100） | 354.1 / 408.6 ms | 354.2 / 424.9 ms |

原始逐次预测和耗时见 `tmp/turn-taking-prompt-holdout-{baseline,source-aware}.json`。
保留集没有声源证据矛盾的场景；20 条样本上的 100% 不可外推为真实环境准确率，尤其
声源 `observation` 是**人为提供的文字事实**，Jev 没有处理音频或进行说话人分离。
如果生产输入只有 ASR 转写而无可靠声源信息，本实验的主要改进无法直接实现。
后续应用前应获取经标注的真实重叠语音、ASR partial 和声源证据，并对二分类
提示词本身重新推理评测；不要直接改动运行时的 fail-open 停播策略。
