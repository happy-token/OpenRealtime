# 前端与会话管理服务分离发布记录

2026-10-13 已完成第一阶段分离：前端在 Cloudflare 独立运行，业务 API 在应用服务器独立容器运行。现有 Python 语音运行时保持原位置和镜像。旧 Web 容器已停止，并保留回滚镜像与配置。

## 职责与部署

会话管理服务与语音交互服务都属于后端。

| 部分 | 职责 | 本次结果 |
| --- | --- | --- |
| 前端 | 页面、文档、交互、浏览器音频采集和播放 | OpenNext Worker；独立构建和发布 |
| 会话管理服务 | 登录、权限、助手配置、资料、记忆与历史 | `apps/backend`；独立 API 容器 |
| 语音交互服务 | 实时识别、判停、打断、Agent / LLM 调用和语音合成 | 原 Python 运行时；未迁移 |

公开域名维持统一：页面由前端 Worker 处理，`/api/*` 转发会话管理服务，`/voice/*` 转发语音交互服务。API 禁止缓存并保留 Cookie、跳转、流式响应；数字人大文件留在源站并保留 Range 下载。前端不加载后台环境文件，不挂载业务数据，也不携带数据库或供应商凭据。

会话管理服务与语音交互服务仍共享部分文件目录和本机控制连接。本阶段完成前端与会话管理服务的运行、构建分离；后续跨机迁移语音需要处理共享存储及受限通信。

## 验证结果

- 前后端类型检查、独立业务构建、Cloudflare 前端构建和前端依赖边界检查通过。
- 基于实际线上源代码的本地端到端测试 10 项通过，覆盖历史布局、恢复、删除、管理员登录导航和业务数据操作。
- 独立进程下真实业务 API 测试 2 项通过，覆盖助手、记忆、知识资料操作及跨来源拒绝。
- 分离相关定向测试 39 项通过；此次文档与服务器代号清理相关测试 19 项通过。
- 线上页面和 API 健康检查通过；API 返回 `cf-cache-status: DYNAMIC` 与 `Cache-Control: private, no-store`。旧 Web 停止后，部署文档仍正常显示，媒体 Range 下载返回 206。
- 会话管理服务空闲容器内存采样约 175 MiB，上限 768 MiB；采样不代表持续通话或并发峰值。本次没有新增完整的线上麦克风通话验收。

完整本地测试套件仍有 4 项既有失败，涉及中文覆盖、默认声音供应商和两个语音克隆 UI 断言；未把这些工作区 UI 变化带入此次发布。文档新增的英文元数据断言已修复并通过。

发布采用当前线上源代码加本次分离变更，避免把工作区其他未发布修改一并上线。线上既有文档目录保留，新增分离部署指南；上一版静态 chunk 保留，以兼容已打开的页面。
