# 2026-10-07 许可句条件预生成与实际句末验收

## 范围与结果

前批已提交 `bdbb161`。本批继续 ADR0137，在既有 actor、预生成控制器、Core 上下文投影及缓存中补上许可句的条件计划，没有增加生产模块、业务 actor 或播放队列。独立构造开关仍默认关闭，未启用产品或重启用户服务。

前批只按已确认内容准备候选，许可句正常播完后反而需要重新生成。本批把「许可句完整播完」作为独立、不可变的私有条件计划。正常精确句末及实际上下文一致时复用；提前停止、未知位置、不同目标、正文/关联或上下文变化时失效并走实际投影。不能以受控缓存命中推断真实延迟收益或 G3 完成。

## 事实与条件边界

- `TurnContent` 保留真正的 `conversation_context` 与投影指纹；另存 `ConditionalSentenceHandoff`，绑定完整播放许可、不可变原句、预计上下文和预计指纹。额外私有上下文上限 64 KiB UTF-8。
- Core 校验原 speech 的 scope、turn、generation、response、来源、交付政策、状态与原文区间，只在私有副本中替换许可句的预计前缀。模型提示明确这是未确认条件计划。Journal、播放账本和已听事实均不写预计内容。
- 完整/预算投影器提供只读假设投影。预算投影只复用来源仍有效的事实摘要；来源失效则完整重投影。它不启动压缩、不发布检查点，也不取消正在运行的事实压缩任务。超出预算或投影器不支持时跳过准备，正式输入仍保留。
- 异步准备最多三次稳定来源快照；完成后继续复验 actor 权限。每份许可最多一次，不逐字请求。
- 交接先要求匹配目标的 terminal 样本回执，位置恰好在许可句尾且已确认文本恰好到原句末。之后正式 ASR、关联、实际完整上下文和指纹共同验证缓存依据。物理停止前不外发候选文本/PCM。

## 故障回归与修复

先将真实生产接续测试改为期望正常句末复用、提前停止重建，四项失败，证明前批未提供条件计划。实现后，Managed/Core/Journal/Bridge 的文本和语音两条链路均满足该契约。

新增候选 TTS 失败回归再次失败：失败候选的缓存文本先公开，租约随后被清理，正式双工合成可能再次请求 TTS 并播出 PCM。两类缓存现在在排出缓存前检查已知错误，显式终止，避免已知失败候选发布残留前缀及错误重合成。原用户输入仍在 Journal，错误通过原正式回复终态报告。

## 验证

生产矩阵 24 项：文本/语音 × 正常句尾 1000/提前停止 600 样本 × 生成已完成/仍活跃 × 完整/预算/异步来源变化投影。正常结束准确两次供应商请求（原回复、候选）；提前结束准确三次（原回复、候选、按实际事实重建）。生成仍活跃时必须先确认旧供应商真实退出。来源变化重投影，停止前新回复零外发，事实记录不提前增加预计句。

另有八种生产故障：错误 scope/response/来源/原文、OMIT 政策、已听前沿超出假设、模型失败、TTS 失败。四项摘要隔离回归验证有/无有效检查点、目标来源失效、在途事实压缩及超预算退出。相关定向 **132 passed**；八个生产模块 Mypy、十二个文件 Ruff 及 diff 检查通过。全量及最终独立审核结果见下方最终记录。

使用受控 ASR、供应商和播放回执；未运行真实模型、录音、数据库或物理 renderer 实验。没有数据库迁移、用户服务重启或远端 push。

## 后续

本批关闭局部条件投影与精确交接测试，不关闭 ADR0137/G3。继续非合作供应商失配清理的完整生产矩阵、产品接入及真实浏览器/数字人验证、手动/DeliverItem 纠正、ADR0138 新 epoch 误打断恢复。实施计划 G0–G5、真实语义/配对延迟/多会话资源公平、诊断/默认录音/只读 Agent 接口等全量未交付项保持开放。

## 最终记录

完成接管窗口修复前的全量 **2289 passed、69 skipped、3 subtests passed，51.47 秒**，这是中间结果。既有独立代码审核复跑 123 项，另验证正式消费首段之后供应商失败：已发首段保留，下一次消费明确失败、残留不外发，清理后可以准备下一候选；该故障增量 APPROVE。随后 Python 审核发现并复现以下接管窗口，最终修复与复跑结果另记。

Python 独立审核进一步复现：TTS child 已记录业务错误，而父任务尚未进入退休/清理阶段；正式消费可以将 `claimed` 置真，随后失败清理取消仍未退出的私有 Brain。新增真实子任务红回归失败于 `claimed=True`。共享 `SpeculativeState.claim` 现在在接管前拒绝这个已知错误、尚未退出的候选，保留原业务原因、私有归属及原退休诊断；不把它标成已释放或粘滞清理故障。回归验证零文本、Brain 不被取消、替代准入被阻止，实际退出后关闭完成。该补强同样不保证任意非合作供应商强制退出。

接管窗口修复后的最终全量：**2290 passed、69 skipped、3 subtests passed，51.20 秒**。定向 132 项、8 个生产模块 Mypy、12 文件 Ruff/diff 检查通过。Python 独立审核最终 141 项通过并 APPROVE；代码审核最终接管增量 APPROVE，独立资源回归 51 项及限定检查通过。两位审核均无确认阻断项。
