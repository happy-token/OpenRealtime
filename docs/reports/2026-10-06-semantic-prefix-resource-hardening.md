# 阶段1：长输入候选资源与构建补强

日期：2026-10-06。依据[实施计划](../design/2026-10-05-voice-correction-implementation-plan.md)和[ADR0135](../adr/0135-bounded-parallel-semantic-candidates.md)。本批完成累计前缀表示和普通长输入重复扫描优化，不关闭整个G1。

## 已实施

`SemanticChunk`用`semantic_end`表示候选覆盖的语义字符范围，不再为每个候选持有完整累计前缀。Buffer保留当前原始文本、当前规范化文本和候选记录；相邻ASR修订的最长共同语义前缀决定哪些ID继续有效。删除的ID不会因之后改回原文而复活，也不能跨输入Buffer复用。合并队列同时撤销源候选ID。

语义位置按去掉空白与标点后的字符计数，与英文单词等分块单位数量不同。发出请求时仍从原始ASR范围重建累计输入、保留标点并冻结请求；等价标点修订、深改写、历史反馈证明和前序未决证据保留。Actor在候选有效性确认后比较范围是否覆盖全文，最新有效全文优先及STOP发出后锁定规则不变。

无ASCII句点的文本首次扫描没有标点后不再对每个阈值块扫描整个余下文本；消费实际标点后重新检查下一段。单位匹配只读取阈值所需数量，强制封口保留原来的65单位探测。含ASCII句点时保留逐尾段检查，避免改变网址、域名、小数和阈值截断后的句点规则；不声称所有输入的构建CPU均为线性。

没有新增生产模块或第二个状态裁决器，没有截断历史、降低分类阈值或增加partial请求。

## 验证与测量

先建立三项失败回归：ASR改回原文导致旧候选复活、其它输入相同文本被判为有效候选、长输入保留内存二次增长。旧实现3失败/9通过；修复后追加普通长中文边界检查次数与网址稳定/强制封口回归。网址测试最初错误地期待跨修订仍保留已跳过的分隔符，已按既有规则修正，未为测试改变生产切分语义。

本地合成中文，每5字一块；构建耗时为不启用tracemalloc时3次中位数，内存为另一次tracemalloc测量：

|字符数|构建中位耗时|保留内存|峰值内存|累计原文|
|---|---|---|---|---|
|1000|1.592ms|62,729B|71,394B|完整保留|
|4000|6.477ms|272,374B|286,938B|完整保留|
|8000|12.487ms|554,502B|582,890B|完整保留|

旧树失败回归的1000/4000字符保留内存分别266,487B/3,468,039B。独立复核在CPU优化前测到1000/4000/8000字符构建中位约52/863/3666ms。以上为本机合成输入定位证据，输入在追踪前生成，内存不含完整进程、日志与在途模型请求；不是语音端到端、模型延迟或P95收益结论。

最终全量Python：1617 passed / 62 skipped / 3 subtests passed，37.37s；供应商skip不算验收。三个生产文件Mypy通过；四个修改文件Ruff通过。独立代码与Python复核均Approve，分别102/115定向测试通过；代码复核另外对照10,000次随机多版本更新与扫描优化前逻辑一致，并复测8000字符构建中位12.52ms。未调用真实模型/renderer、未重启当前服务、未提交Git。

## 剩余边界

有效chunk历史仍随逻辑输入增长，单个英文词、标点串、队列合并和原始文本仍没有总字节/时长预算。每块remainder切片仍复制逐渐缩短的尾串，不能严格宣称总构建CPU渐进线性；ASCII句点密集的特殊路径仍可能反复扫描，单次超长ASR快照与多轮更新也没有总CPU上界。累计请求payload和诊断日志不因本批修改自动有界。

下一项随ADR0136建立可回读的输入证据、输入/回复版本账本、payload预算和超额的可解释终态；持久化失败时不能裁掉唯一输入证据。真实录音oracle、renderer播放/停止证据、多会话容量及真实性能对照仍需完成，G0/G1保持部分完成。
