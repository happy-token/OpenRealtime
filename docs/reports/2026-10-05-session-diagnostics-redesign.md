# 会话诊断看板与采集验证

## 已实现

- 设置侧边栏入口统一命名为「会话诊断」，使用现有管理员登录状态。
- 总览显示响应、打断 P50 / P95 / 样本数，失败轮次、异常断连及恢复成功率。
- 模块数字卡片覆盖 ASR 首文本和最终文本等待、LLM 首文本、TTS 首包、语义判停与语义打断；鼠标悬停或键盘聚焦可查看说明。
- 模块失败、超时、断连可筛选异常会话；重试和恢复统计展开查看。未接通的指标使用 —，不补造零值。
- 服务端 VAD 边界与客户端播放回执关联，只有确认打断且对应旧输出停止才记录打断样本。
- 主动客户端关闭使用 WebSocket 1000，正常关闭不进入异常重连。停止事件泵后仍会终结待恢复事件，避免恢复统计永久停留在处理中。

## 口径与限制

响应与打断延迟目前使用服务端 VAD 时间估算和客户端回执的服务端接收时间，包含检测误差与回传耗时，并非精确的客户端音频时钟测量。历史记录没有这些边界时不能回填。

模块失败展示调用事件，提供商失败存在时以提供商事件为主、能力失败作为回退；同一窗口内同时存在独立的提供商和能力错误时，当前聚合不能逐个事件关联去重。整体失败轮次按 Session 与响应标识去重。部分模块尚无独立断连与恢复采集，界面明确展示 —。
