# 更低成本与更高灵活性

核查日期：2026-10-12。

OpenRealtime 将听、回答、说和交互判断分别配置。你可以选择经济的语音识别与合成，保留自己已有的文本模型或 Chat Agent，并根据需要更换服务。**选择合适的组合，语音成本可低于 GPT-Realtime 这类端到端方案。**

## 成本优势从哪里来

- 识别、回答和声音可以分别选型，按预算与体验组合。
- 已有 Chat Agent 可以通过适配复用，业务回答不必迁移到另一个语音模型。
- 云 API 路线无需自建模型 GPU 推理；数字人可以后续按需添加。
- 根据应用选择声音、模型和交互决策，控制每个环节的费用。

## 比较时算什么

```text
OpenRealtime 组合费用
= ASR + 回答模型/Chat Agent + TTS + 话轮决策
  + 工具与检索 + 应用运行费用 + 可选数字人

端到端方案费用
= 语音/文本/图像模型用量 + 工具与检索
  + 应用运行费用 + 可选数字人
```

服务组合、讲话比例、历史长度、缓存、打断和失败重试会改变结果。应比较同一个任务与目标质量下的总费用，记录具体模型、语言、网络和使用量。

## 当前官方价格能说明什么

[OpenAI 官方价格](https://developers.openai.com/api/docs/pricing)列出 GPT-Realtime-2.1 的音频输入／输出为每百万 token 32／64 美元，mini 为 10／20 美元。[Realtime 计费说明](https://developers.openai.com/api/docs/guides/voice-latency-cost)还说明历史内容、缓存和输入转写影响账单。

[DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)列出 Flash 文本模型的非缓存输入／输出为高峰每百万 token 0.3／1.2 美元，非高峰 0.15／0.6 美元。这只是可选择的文本模型价格，不能直接用文本与音频 token 单价相除，得到整套语音服务的节省比例。

豆包等语音服务应按自己的 ASR、TTS 产品、音色与套餐核对[官方计费](https://www.volcengine.com/docs/6561/1359370)。本轮未完成该页面当前全文核查，未在此引用语音单价；也没有新增同任务账单对照。

产品亮点是**可以通过经济的组件组合降低语音成本，并自由调整体验与预算**。固定节省比例、所有组合均更便宜或同等语音质量，需要具体配置和同条件测量支持。

## 灵活性带来什么

你可以保留自己的回答逻辑与业务资料，单独调整声音与交互策略；也可以从纯语音起步，再增加数字人。功能与成本均按所选服务组合变化。原生端到端服务也有工具与交互能力，选型要考虑语音质量、延迟和维护工作。
