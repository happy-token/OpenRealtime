# 宣传亮点、实现依据与验收边界

核查日期：2026-10-09。实现依据来自当前本地工作区，可能包含尚未提交内容。本文不将接口存在、受控测试、真实供应商调用和完整体验验收混为一谈。

2026-10-12 产品表达补充：首屏恢复可自定义、可打断的语音 Agent，丰富功能与可选数字人；低成本按[服务组合与总费用](COST-AND-FLEXIBILITY.md)说明；现有文本 Chat Agent 的[兼容接口与适配器接入](../guides/CHAT-AGENT-INTEGRATION.md)单列，不与编码／办事后台的统一任务体验混为一项。

## 1. 证据等级

| 等级 | 证明范围 | 不能据此证明 |
| --- | --- | --- |
| I 实现 | 可读取的实际代码和配置入口 | 默认启用、部署可用、供应商效果 |
| T 受控回归 | 给定输入/故障条件下的逻辑行为 | 真实麦克风、声源识别、网络、总体准确率 |
| P 真实供应商 | 某模型/接口/配置下的真实请求 | 完整端到端体验、不同地区/版本普适 |
| B 真实浏览器 | 给定页面/浏览器/音频条件的行为 | 物理扬声器输出、所有供应商/设备 |
| E 完整体验 | 固定版本/供应商/设备/网络的全链路任务 | 下一版本自动通过，或同条件竞品领先 |
| C 比较实验 | 同工作负载和明确条件的横向对照 | 所有语言、场景、网络的全面领先 |

I/T/P/B 是不同证据类型，不是自动递增的总分。历史 E 报告只支持其版本与配置。

## 4. 可使用与待验证文案

可使用：

- 面向全球开发者的可组合实时语音与数字人Agent运行时；英文API路线仍需补齐。
- Jev可用于判停与打断，大模型独立负责回答。
- 云API路线无需自建GPU推理服务。
- 保留自己的Agent、声音和知识，数字人服务负责呈现。
- 支持附和、停止、纠正与新请求的语义判断和配置策略。

规划亮点（TODO）：连接已有 Agent，通过语音发起任务、追问进度并补充要求。已有适配基础不等于完整交付；按[定位中的验收清单](POSITIONING.md)补齐统一配置、任务反馈与取消边界后再列为现成能力。

要有新证据再使用：更快/更便宜/目标语言更准确、不会误打断、300ms整链回应、GPU零成本、无限时长、生产全面就绪、设备协同已落地、所有MCP/Agent零代码接入。

## 5. 发布材料验收

每支Demo记录产品版本、供应商与模型、语音/数字人路线、浏览器/网络、场景脚本和已知失败。视频中的停播/回应来自实际操作；剪辑压缩等待时，不把剪辑节奏作为响应速度证据。README将机制、配置与效果分别呈现，给已有数字链接和范围。

对比实验按[竞品研究](COMPETITIVE-ANALYSIS.md)统一模型、场景和费用口径；失败、超时和取消尝试纳入结果。由[定位](POSITIONING.md)决定优先验证哪些场景，不为凑领先数字挑容易样例。
