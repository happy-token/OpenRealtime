# Use a stateful process rail and persistent preview in Avatar Studio

Desktop Avatar Studio uses an Anam-inspired composition with a left process rail for `数字人图片`, optional `实时驱动创建`, repeatable optional `动作创建`, per-action `口型模型准备`, and `完成`, alongside a persistent large image or video preview stage. The rail is revisable rather than a one-way wizard: completed stages collapse to summaries, image-only creation may skip both capability stages, confirmed actions prepare in the background while another action is created, and media evidence remains visually opaque while controls inherit shared glass preferences. When adding a capability to an existing Avatar, the image stage is completed and read-only, identifies the selected Avatar, offers only a return to the library to change the target, and starts focus on the requested capability; entry from an Avatar detail preselects it and bypasses the picker. Mobile keeps the preview above a single-column collapsible process rail.
