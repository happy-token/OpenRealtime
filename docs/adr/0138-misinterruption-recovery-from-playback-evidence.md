# ADR 0138：依据播放证据恢复误打断

日期：2026-10-05。状态：Proposed，前置事实边界已局部实施，恢复动作待实施。

## 决策方向

打断执行是不可撤回的历史动作。迟到同批不打断结果不能切回播放；ASR改写或明确新证据可创建恢复版本。原输出仍有效且位置可靠才续播；位置未知、流失效时按已确认内容生成续答。新补充改变答案则修正，不恢复旧答案。

恢复具备截止、幂等和被新输入/结束取消的规则。无停播确认不得假设已停，也不得重叠播放新回复。

## 2026-10-06设计补充

STOP_REQUESTED即锁定业务动作，客户端回执更新为STOP_CONFIRMED；缺回执为STOP_UNKNOWN，服务端取消完成不能冒充物理事实。未知状态有协议安全reset/重新绑定或明确失败出口，不能永久等待或盲目新交付。

恢复由actor创建新回复版本/播放epoch；同stop_command_id幂等，新epoch允许再次合法打断。恢复只使用可靠已播事实，不能将“准备允许播完”的句子当已听见。

执行前旧停止证据被最新有效不打断裁决替代时忽略（2026-10-06用户确认）；执行后同批反结果不撤销。可靠新证据才允许创建恢复动作。

## 依赖与验收

依赖0136/0137。需求AC07/08及实施计划阶段4。真实误打断恢复与断连回执测试。
