# ADR 0141：预生成输出预算与清理归属

日期：2026-10-07。状态：Accepted，限本地缓存与生命周期实现；不代表 ADR0137 或完整 G3 验收。

## 背景

一般补充若要与旧回复句末等待重叠生成，必须先限制既有预生成缓存。原两类缓存保留所有文本/PCM，没有候选驻留期限；新候选可在旧请求实际退出前启动。只有取消任务，不能证明供应商清理完成，尤其供应商正在自然 `finally` 中时。

## 决策

复用 SpeculativeStreamingBrain、SpeculativeSpeechPipeline 与 ResponsePrefetchController。共享 `speculative_budget.py` 只负责输出预算、缓存缓冲与供应商清理归属，不增加语义 actor、回复账本或业务播放队列。

默认候选保护：文本 UTF-8 64 KiB/1024 块；音频及字幕元数据合计 8 MiB/2048 块；PCM 对应音频时长 30 秒；候选从 prepare 起驻留 30 秒。预算可通过构造参数注入，属于工程保护，不是延迟 SLO。追加前检查，单包超限不入缓存，完成的候选也在绝对驻留期限清空。错误记录不保留异常栈、大包或原异常链；输入与上下文不截断。

未正式消费的候选超限：标记原因、清缓存、退休旧供应商；正式请求只在旧供应商真实结束且清理确认后绕过缓存。已经正式消费：排空 deque，满缓存等待消费，继续同一供应商；不从头重放文本/音频。单个供应商包超过上限时明确失败。Brain 和 TTS 使用同一正式租约，包括缓存未命中路径；空回复释放不存在的 TTS 租约。已正式 claim 的响应沿用 Core 原截止，候选驻留计时不重置或延长正式截止。

未 claim 候选采用软退休：不取消未知的供应商 `__anext__`，避免中断其自然清理；取消内部队列等待、停止缓存追加并保留归属。未退出的供应商继续占唯一槽位，新准入有界报 pending。TTL 限制缓存驻留，不能硬限制任意供应商请求寿命；实际退出依赖供应商自身完成/超时。正式响应继续现有 Core 取消契约。本 ADR 不宣称任意供应商可强制释放。

关闭通过每层共享、shield 的 owned close task 确认：预生成控制器调用缓存 close，工具聊天路由传到聊天缓存；Core 与 Managed 重复/取消关闭等待者仍等待同一真实清理。关闭未完成时保持会话/历史删除保护；供应商清理失败时保留 suspended 所有权，终止事件泵并显式返回错误，不伪造注销成功。actor 对分类器、预生成和证据 writer 独立收尾，失败仍结束 Core 事件流；末次准入 await 后重新检查关闭意图，防止旧清理释放后启动新供应商。

## 验证与后续

先红后绿覆盖实际供应商循环、超限大包内存留存、自然/异常清理竞争、正式背压、空回复及真实 actor → Core/Managed 关闭。生产 speech 分支补接已有 response.prefetch 观察接口。见[实施报告](../reports/2026-10-07-speculative-output-budgets.md)。

本批为一般补充提前生成的前置。句末重叠预生成、交接时 heard_frontier 重验与重生成、误打断恢复、真实 renderer/供应商延迟及全局资源预算仍按原计划实施。
