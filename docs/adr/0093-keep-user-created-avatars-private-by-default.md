# Keep user-created Avatars private by default

An Avatar saved from a user's uploaded or HappyImage-generated source is a Private Avatar owned by that authenticated account; generation with personal quota never implies workspace publication. Built-ins and explicitly published entries form the Shared Avatar catalog, publication requires a separate authorized action, private media remains behind authorized signed access, and ordinary users may rename, delete, prepare, or backfill only their own Avatars while administrators manage shared assets without silently publishing private ones.
