# Launch Avatar conversations through the home Session Configuration Workbench

The `开始对话` command on an Avatar asset card navigates to the existing home Session Configuration Workbench with the selected `avatar_id`, rather than opening a new launch panel or immediately starting a session from hidden defaults. The workbench expands the Avatar section and may prefill that Avatar's Last Successful Avatar Session Choice, while the user can still change realtime versus segmented rendering, image versus one accepted action, and a compatible Lip-sync Model. Only the workbench's existing final start command launches services. If the selected image or accepted action lacks a ready derivative for the selected model, the workbench preserves the configuration, starts only that source/model preparation, and opens a waiting dialog; success automatically continues into the requested conversation without an offline preview.
