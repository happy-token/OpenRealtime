# ADR 0136：输入与回复版本及补充纠正

日期：2026-10-05；2026-10-06更新。状态：Proposed，部分实施；完整关联与G2未验收。

2026-10-07更新：已补同一授权线程的跨 Voice Session/设备历史与已归档版本恢复。投影命令属于当前 Session，原 Journal item 保留旧上下文；公开追加和实时命令仍限定当前 Session。账本只在恢复屏障重建当前输入/回复身份，实时提交/绑定后投影不能回滚。旧回复始终无输出许可，不恢复执行租约或自动请求；legacy兼容与损坏元数据失败有回归。完整跨Session动作幂等、未归档回复检查点、完整语义关联/G2仍未关闭。实施与测试范围见[报告](../reports/2026-10-07-cross-session-revision-restoration.md)，状态继续Proposed。

## 决策方向

判停完整触发生成不关闭输入关联。以input_version与response_version隔离生成、交付和补充；未播放旧生成可取消重做。保留原输入、ASR修订、补充与替代关系。短纠正不按长度丢弃；新话题与补充需语义关联，不仅凭时间。

预生成Controller可复用，但不能将其缓存失效当作正式已播回复的修正实现。迟到旧文本/音频必须在交付边界拒绝。

## 2026-10-06设计补充

ReplyRevisionController是actor同步命令驱动的版本账本/纯规划器，不另建业务actor，不自行判关联或控制播放。既有Generation保持执行租约，input/reply版本是关联身份。

输出自然结束不使用户未决输入失效。优先补UNCERTAIN重要补充与噪声的不同有界出口；不能仅以恢复截止丢弃全部未确认文本。分类结论与截止提交理由分别保存，禁止将TIMEOUT处置伪装JEV COMPLETE。

未播旧版本禁止新交付；已播的一般补充在0137使用精确当前句许可，不把整个旧generation继续放行。输入证据入Journal，不用扩大实时任务元数据保存全部历史。

## 依赖与验收

依赖阶段0契约/播放能力基线及0135补强。需求AC04/09/11/14及实施计划阶段2。尚未宣称正式回复修正已落地。

## 2026-10-06局部实施记录

针对Session95a9b382补上旧播放自然结束后的未决输入出口：自然完成不确认打断，但不再阻塞保留文本提交；晚到全文分类仍有效，自然结束后的旧前缀不覆盖全文接纳判断，已执行停播锁保留。精确附和继续抑制新回复，原始模型标签与阈值降级单独记录。[故障与验证报告](../reports/2026-10-06-session-95a9b382-lost-followup.md)包含17项事件回放与完整Python回归。尚在播放的截止策略、任意噪声判别和input/reply版本账本未完成，状态仍为Proposed，AC11仅部分实现。


## 输入证据前置条件实施

2026-10-06已接入Journal输入证据适配器、逻辑输入预算和管理员分页回读。ASR修订使用替换位置与后缀重建；有效分类结果与候选关联。独立证据scope不进入主LLM历史；持久确认失败显式终止会话，不把内存ack称为落盘。实际tenant/user/thread从服务端会话记录解析，支持续接线程。新增的是存储适配边界，没有第二个语义actor。

[实施报告](../reports/2026-10-06-input-evidence-and-resource-budgets.md)列出预算、采集范围、故障出口及测试限制。该前置批次尚未实现正式input/reply版本账本；后续首批实现见下文。

## 输入 / 回复版本首批实施

2026-10-06已新增actor同步驱动的ReplyRevisionController：保存当前逻辑输入/回复版本及替代关系，禁止重发绑定恢复撤销许可，不增业务actor。输入及助手Journal携带版本；独立证据区分ASR观察上下文与正式提交上下文。未播旧输出取消后，在engine、生产装饰链出队及WebSocket最终出口复验同一许可，终态事实不被过滤。

分类原结论与admission_reason分离，未确认重叠输入截止有保留证据的显式失败出口；STOP已执行仍锁定。自然完成与取消竞争保留原回复上下文，结算原播报并发出停播通知，不重复回复终态。

新增21项回归覆盖上述机制，详细范围见[版本与交付隔离报告](../reports/2026-10-06-reply-version-delivery-isolation.md)。一般补充语义关联、跨Session重建/幂等、播放中当前句许可与真实G2尚未完成；0137/0138继续待实施，不能将整回复失效当作句末衔接。ADR继续Proposed。

## 最终ASR关联策略首批

2026-10-06继续实施：关联是独立可替换的同步策略，由既有actor在正式ASR final提交时核验。默认有限规则优先，可靠全文CORRECTION复用；不再把“未播”本身当补充依据。未知关系保留独立原文、父引用及澄清提示；策略异常先保留final证据，再降级未确定，不终止输入。正式关联结果进入事件/Journal/输入证据，文本与音频预生成缓存比较关联提示。

播放事实与许可撤销独立。开始回执晚于生成完成/取消时仍按原response/turn/generation记录，不重开许可；取消后的临时映射缺失时复用持久交付记录。已听助手历史由交付事实投影，不按整个turn或提交时标志永久删除。详见[本批报告](../reports/2026-10-06-final-input-association.md)。有限策略、模型提示和本地回归不关闭完整语义关联/G2；ADR仍Proposed，跨Session及0137/0138继续开放。
