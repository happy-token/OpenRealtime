# Add actions to the selected existing Avatar

Selecting an existing Avatar image in Avatar Studio, or entering Studio from an Avatar detail's `创建动作` command, fixes that original `avatar_id` and creates actions as children of the same aggregate. The UI identifies the target Avatar by name and source image and never copies its image or creates a duplicate Avatar merely to add motion. A new Avatar ID is created only when the user saves a newly uploaded or HappyImage-generated candidate; an explicit `创建副本` command may open such a new draft, but it never copies actions automatically.
