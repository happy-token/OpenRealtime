# Soft-delete Avatar aggregates through a thirty-day recycle bin

Deleting an Avatar moves the complete aggregate into a 30-day recycle bin and immediately excludes it and all child actions from normal asset lists, new session selection, and conversation tests. The confirmation reports how many live sessions use the Avatar or affected action; once confirmed, those sessions stop their Avatar Renderer and continue as explicitly labeled audio-only conversations without automatic visual substitution. During retention, restoration recovers the source image, actions, preparation results, and bindings together but never silently rebinds a live session; after expiry, OpenRealtime permanently removes its authoritative records and owned media. Deleting one action remains an independent 30-day recoverable operation inside the parent Avatar: it leaves normal choices immediately, keeps its original ID, video, and prepared model results for restoration, and permanently removes only that action's media and derivatives after expiry. HappyImage generation history has an independent lifecycle, while a linked provider resource is remotely destroyed only when it is exclusively owned by this Avatar and the provider API can confirm deletion; otherwise permanent deletion unlinks it and clearly reports that the external resource remains.
