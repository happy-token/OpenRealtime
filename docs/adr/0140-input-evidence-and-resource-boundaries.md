# ADR 0140：输入证据与逻辑输入资源边界

日期：2026-10-06。状态：Accepted；本地实现与确定性回归，不代表完整真实语音验收。

## 背景

0135限制在途并发，不能限制整个逻辑输入的ASR历史、候选和日志。0136需要可回读输入证据来关联后续纠正；异步debug log返回成功不能代表落盘。实时裁决不应自行维护数据库或扩大内存保存所有历史。

## 决策

复用Conversation Journal的INTERNAL结构化内容，在按tenant/user/thread/voice_session隔离的独立证据thread保存ASR替换链、候选与有效结果。主模型投影只读取主thread。存储适配器使用一个有序、有数量/字节/等待限制的写入worker，不新增语义actor或数据库表。

receipt验证item身份及内容digest，明确durable能力；内存确认不允许作为持久确认。正常路径不在每次模型请求前等待IO，写入异步失败必有会话级退出，包括输入已完成之后的失败。证据保存范围不是全部原始provider事件、物理音频或实际播放事实。

逻辑输入设文本、版本、候选、绝对时长及累计证据预算。预算是可配置工程保护，不是模型准确率或延迟SLO。超限冻结输入并取消分类/预生成，尝试完整记录拒绝快照；无法完整捕获或确认时明确报告缺失，不截断后继续判断。通过现有失败协议终止会话，释放未保存内存，不把无法持久保存的输入称为可恢复。

管理员分页回读复用当前登录代理；实际scope从服务端会话记录解析。机器只读身份认证不在本ADR范围。删除Session只删除其专属证据；主线程只有原子检查所有记录均属所选Session、且本进程无已注册会话引用时，才整线程删除。不具备原子归属删除的adapter保留主线程。内存同锁，Postgres锁线程version行并在事务内检查/删除。进程内活动目录同步占用空闲thread，删除期间拒绝新的register，finally释放，不仅在删除前检查一次。多进程活动目录与共享thread按item删除另行设计。

## 实施与验证

实现见 `conversation_journal/input_evidence.py`、SemanticInputBudget、现有协调器/级联引擎/WebSocket、ApplicationRuntime及控制平面。测试覆盖确认/超时/取消、ASR改写、预算、晚到失败、真实管线关闭、共享主线程保留和模拟浏览器失败行为。[实施报告](../reports/2026-10-06-input-evidence-and-resource-budgets.md)记录具体范围、配置、结果和限制。

本ADR为0136提供输入证据与资源前置条件，不改变其Proposed状态，不代表回复版本纠正/句尾衔接/误打断恢复已实施。
