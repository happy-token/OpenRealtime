# Prepare the selected Avatar source during session startup

The home Session Configuration Workbench keeps accepted actions visible and selectable even when the currently chosen Lip-sync Model has not prepared them. Pressing `开始对话` explicitly authorizes preparation of exactly the selected image-or-action and model pair, preserves the current configuration, and opens a minimizable waiting dialog that shows stage, expected time, and failure details. The durable task continues if the dialog is minimized or the user navigates away: it automatically continues into conversation only while the user remains in the workbench, otherwise it sends a completion notice and waits for another explicit start command so it never activates a microphone or session in the background. `取消启动` cancels the requested launch, but any valid preparation result already committed remains reusable. This demand-driven path complements but does not replace explicit asset-management backfill.
