# ADR 0135：有界并行语义候选与确定性结果裁决

日期：2026-10-05。状态：Accepted；并行基础机制已实施并有局部/真实启用证据。2026-10-06复核后，完整安全与性能验收需补强，见下文。

## 背景

独立chunk降低partial请求量，但原调度一次只执行一个候选，且同类任务key和请求token被复用。增加JEV客户端并发不能消除本会话串行等待。直接创建并发任务会造成晚到结果覆盖新状态、请求token互相失效、重复打断。

## 决策

SemanticChunkScheduler维护有界inflight映射，产品装配默认2，局部API默认1兼容旧调用；共享JEV槽位仍独立。每候选独立chunk任务key和令牌，输入actor裁决结果。改写使对应候选无效；取消按任务族清理。判停请求使用累计语义；仅覆盖当前有效整轮文本的结果可决定提交，晚到前缀结果不能清空该状态。有效打断一旦执行，清理同批任务并锁定；不同输入identity与旧target回复结果不能生效。

候选溢出合并仍待发部分，不重发已在途块。保持标点、稳定尾段、停说边界，不按每字符请求。

## 后果

降低串行等待，但请求并发上升。相同文本的重复语义请求后续需要独立证据评估，不通过跳过用户补充减少请求。JEV槽位小于候选并发时仍会排队。句末纠正与误打断恢复不在本ADR实施范围，见0136—0138。

## 验收

并发、乱序、累计文本、改写、取消、确认打断锁定及原规则回归。真实测试必须证明第二候选在前候选结束前发起，而不是仅证明多次模型调用成功。


## 实施证据

- SemanticChunkScheduler/CoordinatedTurnManager实现候选映射、独立任务、累积EOT及裁决；配置默认产品并发2。
- 控制事件回归覆盖最新完整先返回、旧完整不能覆盖最新不完整、打断取消兄弟任务、晚到非打断前缀不阻塞最新IGNORE、改写保留有效兄弟候选与并发上限。
- 最终Realtime/TurnPolicy429 passed；全量1488 passed（最后令牌保护前），最终类型检查通过；真实语音3 passed。
- Session 3c04de17-fd47-4e36-9436-f7fc8ed23d02 在真实判停时间线上有重叠请求。历史单飞方案见2026-10-05连接/JEV分段报告；该报告描述的是本ADR实施前行为。

## 2026-10-06复核与补强

- 并发容量不改变模型输入语义：复核时仅并发大于1使用累计判停前缀；本轮已统一1/2及提示词，保留原始标点，再进行容量对照。
- 用户确认：发出STOP前最新有效完整输入优先；其不打断裁决已替代的旧停止前缀不得触发。STOP发出后立即锁定，同批相反结果不撤销；不是等客户端回执才锁。
- 执行前冲突规则、等价修订证据和截止保留已补回归；语义打断模型范围显式绑定累计快照，未知前序不能被尾部附和掩盖。底层有效性仍使用规范化前缀，不把它当作模型正确性证明。
- 在途数量有界不证明完成任务元数据有界；补长输入/改写、关闭清理与共享槽位隔离验证。
- 3次真实短句只支持冒烟与并行启用，不支持性能因果或P95达标。完整门槛见[实验计划](../design/2026-10-06-voice-interaction-experiment-plan.md)。本轮代码与验证见[实施报告](../reports/2026-10-06-parallel-hardening-implementation.md)，长输入历史资源界和完整G1仍开放。

## 本轮实施补充

已落实调用截止、残留槽位、合作取消交接、关闭撤销结果有效性，及完成任务/queued token清理。局部规则读取独立块和已确认前序证据；模型读取显式累计文本，兼容旧插件入口。未增第二个决策actor，未增加逐partial触发，未实现0136—0138。

## 长输入表示补强

2026-10-06继续实施：候选以semantic_end及所属Buffer的有效ID绑定语义范围，当前规范化文本与相邻ASR最长共同前缀决定有效性。累计prefix不再逐候选复制；被改写/合并淘汰的ID不能因原文恢复复活，跨输入同文也不能有效。模型输入仍在签发时从原始文本范围冻结，完整范围比较与既有STOP锁定规则保持不变。

普通长输入避免重复全尾标点/单位扫描，ASCII句点特殊路径保留兼容规则。内存、CPU、回归和未完成预算见[长输入补强报告](../reports/2026-10-06-semantic-prefix-resource-hardening.md)。总历史、payload和持久证据预算仍须与0136衔接，完整G1没有关闭。
