# Use the home panel's FAB overlay pattern for Avatar Studio's narrow-viewport config

Avatar Studio's narrow-viewport config card (the Studio Config Overlay) is modeled on the home workbench's `liquidPanel` — a collapsed settings-button FAB that opens into a config panel floating over the persistent preview — rather than reusing `ConfigDrawer`'s session-variant full-viewport modal, because the FAB is the pattern that actually floats config over a visible preview, while `ConfigDrawer`'s modal covers the whole viewport and hides the preview entirely. It evolves the existing `mobileConfigOpen` mechanism already built for Avatar Studio rather than replacing it, and applies uniformly across all three Avatar Studio tools/steps. The overlay is hand-rolled with plain CSS transitions and React state, consistent with all three overlay implementations already in this codebase (Avatar Studio's own drawer, `ConfigDrawer`, and `liquidPanel` itself); no overlay/dialog library (Radix, vaul, Framer Motion) is introduced, even though none of the three existing implementations share a primitive today, to avoid a new dependency for a single-page redesign.
