# ADR 0143：显式回复与模型交付共享上下文纠正契约

日期：2026-10-07。状态：Accepted，限当前会话内的请求准入和纠正编排；不关闭 ADR0136/0137 或 G2/G3。

## 背景

自动 ASR 回复已有有限新版本纠正，显式 RequestResponse 和 DeliverItem.MODEL_RESPONSE 却没有相同编排。手动文字缺少逻辑输入身份；工具结果作为模型触发源时不能代替用户授权。迟到 Started、取消准入及幂等重放还可能把纠正所有者退回旧请求。

## 决策

沿用现有输入 actor、ReplyRevisionController、TurnController、Core 与 Journal，不增加业务 actor、生产模块或播放队列。

Core 从已投影且完成、模型可见、同会话与同 turn/generation 的 USER_INPUT 取得输入锚。新的未版本化手动文字用 Journal item_id 建立版本一；已有 ASR 输入沿用身份及文本校验。工具/委派结果可以触发模型回复，仍作为上下文和交付父项；纠正回到原用户输入，不能取得新的动作权限。

TurnController 保存一份当前可纠正请求。显式请求在准入时登记；模型交付在匹配原准入身份的 Started 时登记。合法队列交付开始只替换当前回复所有者，并保留已排队合法后继。新用户输入、显式请求或取消撤销旧队列权限。旧 ResponseStarted 只记录自己的事实和父项，不能清空较新请求。

准入异常与 CancelledError 仅在赋值版本仍匹配时回滚原有效队列；期间已开始的合法交付使用已保存的 Started 事实恢复最新所有者，未开始的后继继续排队。内部自动/纠正请求与公开调用共用准入记录。相同幂等键保存原命令与准入结果；重复命令不得重新授权。并发重放等待同一准入结果，取消等待者不取消原请求。不同命令内容使用同键时拒绝。RequestResponse 与 MODEL_RESPONSE 的 delivery:<id> 共用回复身份索引，非法新键别名在修改输出/队列记录前拒绝，不得破坏原合法交付。失败准入移除记录供调用者重试。该记录只属于当前会话内存，不声称跨 Session 持久动作幂等。

手动输入替换未提交语音时，先保留旧原文及替换来源的输入证据；证据失败维持原失败归属。启动已有 ASR 输入的回复不丢弃后续语音补充。请求准入与交付许可分别检查，准备时合法 yield 不变成同步请求失败。

新回复继续使用 actor 签发的许可、原输入版本、递增 reply_version、supersedes_response_id、最多两次纠正与原绝对截止；资源清理、真实已听事实、播放停止以及工具/委派重放拒绝使用原有边界。

## 验证与限制

[实施报告](../reports/2026-10-07-explicit-context-repair.md)记录真实 Managed/Core/Journal/Bridge 组合回归、排队交错及取消/重放反例。归一化 ASR、模型、TTS 和回执受控；不以测试通过推断实际供应商速度或物理扬声器停止。

一般补充的完整异常矩阵、真实供应商/录音/数字人、误打断恢复 ADR0138、跨 Session 未知动作持久对账和其他实施轨道仍按原计划推进。
