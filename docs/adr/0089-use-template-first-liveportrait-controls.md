# Use template-first LivePortrait controls

Avatar Studio presents LivePortrait as a template-first creative tool: continuous previewable driving-performance cards and a plain-language motion-strength choice remain visible, while transfer scope and supported stabilization or compositing corrections live in a collapsed `高级调整` disclosure. Recommended defaults make `选择模板 → 生成预览` sufficient for ordinary creation, and provider parameter names or controls that do not affect the bound runtime are never exposed in the primary flow.
