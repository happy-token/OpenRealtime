# 角色配置：从形象到实际能力

[文档导航](../README.md) · [首页使用指南](../QUICK-START.md)

从左侧「角色」进入已有角色，在详情中打开「角色设置」。使用演示或个人角色配置，确认保存结果后再开始会话。

| 配置 | 作用 | 注意 |
| --- | --- | --- |
| 名称、声音 | 角色身份与语音输出 | 声音需对应已配置且可用的 TTS；试听后确认真实会话生效 |
| 人设 | 对话风格与角色说明 | 人设不能替代实际工具、资料或权限 |
| 高级供应商配置 | ASR/LLM 供应商覆盖 | 留空使用供应商默认配置；完整模型/接口设置在相应服务配置入口 |
| 工具使用 | 选择角色可调用的内置、个人或共享工具 | 权限入口与角色选择分开；自定义工具草稿不等于已接入可执行 MCP |
| 知识库 | 绑定角色可以检索的资料 | 导入后先测试检索，再在真实对话验证回答；不要仅凭勾选推断效果 |
| 长期记忆 | 按当前用户与角色范围保存长期信息 | 开关与已存记忆的管理不同；查看数据管理指南 |
| 呈现模式 | 配置语音、视频/动作、口型或实时数字人入口 | 不同模式有不同素材和服务前提，预制视频不能当作实时口型 |

模型服务与供应商管理可从左下设置入口进入。主屏右侧面板按模式展示视觉主题或数字人形象；底部动作入口在部分模式不可用，实时数字人模式不能假定支持同样的动作列表。

参见[工具权限](../TOOL-PERMISSIONS.md)、[知识库](../KNOWLEDGE-BASE-GUIDE.md)、[记忆与历史](../MEMORY-AND-HISTORY-GUIDE.md)、[数字人](../DIGITAL-HUMAN-DRIVING.md)。
